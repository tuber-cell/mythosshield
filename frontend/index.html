What this scan does
1. Parses requirements.txt and package.json to build a real SBOM
2. Scans for AI model files (.pt, .h5, .onnx, .pkl…) for the AIBOM
3. Queries OSV.dev live for every exact component/version — the same open vulnerability database tools like Dependabot use
4. Severity comes from each advisory's own published data — nothing is invented if a component turns out clean
5. Calculates a CERT-In compliance score from real, verifiable signals only
